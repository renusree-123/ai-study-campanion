# AI Study Companion

An AI-powered learning and growth workspace. Organise what you are learning into
**Spaces** and **Projects**, add your own PDFs, learn from a tutor that answers
**only from your material and cites the page**, take **adaptive quizzes**, and
watch **concept mastery** move over time — with recommendations for what to do next.

The point of the product is the loop, not the individual features:

```
materials → knowledge → tutor → quiz → mastery → growth → recommendation → back to learning
```

---

## Quick start

```bash
git clone <this-repo> && cd ai-study-companion
npm install
cp .env.example .env
npm run setup     # generate client, create the database, seed demo data
npm run dev       # http://localhost:3000
```

Sign in with a seeded account (there are one-click buttons on the sign-in page):

| Role    | Email               | Password            |
| ------- | ------------------- | ------------------- |
| Learner | `learner@demo.dev`  | `demo-password-123` |
| Admin   | `admin@demo.dev`    | `demo-password-123` |

### It runs with no API key

`ANTHROPIC_API_KEY` is **optional**. Without one the app falls back to a
deterministic offline provider that answers extractively from your own uploaded
material, generates quiz questions from it, grades against rubrics, and refuses
questions the material does not cover — so every product flow, the test suite
and the evaluation harness all work with zero credentials. The UI labels the
provider clearly so nobody mistakes it for model output.

To use the real model, put a key in `.env`:

```bash
ANTHROPIC_API_KEY="sk-ant-..."
```

Everything then routes to `claude-opus-5` through the same interfaces.

## What is built

**Product**

- Email/password authentication with role-based access (learner / administrator)
- Spaces → Projects, each project fully isolated from every other
- PDF upload with a visible multi-stage background pipeline (text layer, layout
  reconstruction, structure-aware chunking, concept extraction, summarisation),
  plus a vision fallback for pages with no text layer
- AI Tutor: streaming, grounded in your material, with `Document — Page N`
  citations, and an explicit refusal when the material does not support an answer
- Adaptive quiz: multiple-choice and open-response, with concept and difficulty
  chosen from your modelled ability rather than the last answer
- AI-graded open answers with rubric-level feedback (covered / missing points)
- Concept mastery, growth analysis, project analytics, global analytics
- Persistent learning context carried across sessions
- Recommendations generated by background workflows off real events
- Admin dashboard: users, spaces, projects, activity, learning analytics,
  AI usage and cost, AI evaluation, system health

**Engineering**

- Durable database-backed job queue: leases, retries with backoff, crash
  recovery, dedupe keys, progress reporting
- Transactional-outbox event bus driving the intelligent workflows
- Hybrid retrieval (BM25 + hashed embeddings, RRF fusion, LLM rerank) with a
  relevance floor that is what makes honest refusal possible
- Provider-agnostic AI layer with retries, timeouts, model fallback, per-request
  usage/latency/cost accounting, and a versioned prompt registry
- A controlled capability layer: the model can only reach registered, schema-
  validated, authorised, audited tools — and cannot write state from a read path
- 123 tests covering auth, isolation, retrieval, mastery, adaptive selection,
  background processing, idempotency, structured outputs and XSS safety
- An evaluation suite with regression detection, runnable in CI

## Commands

| Command                | What it does                                                     |
| ---------------------- | ---------------------------------------------------------------- |
| `npm run dev`          | Dev server, with the background worker in-process                 |
| `npm run build`        | Production build                                                  |
| `npm start`            | Run the production build                                          |
| `npm run worker`       | Standalone background worker (set `WORKER_IN_PROCESS=false`)      |
| `npm test`             | Full test suite                                                   |
| `npm run eval`         | AI evaluation suite; exits non-zero on a regression               |
| `npm run eval -- tutor`| One evaluation suite                                              |
| `npm run setup`        | Generate client + create database + seed                          |
| `npm run db:reset`     | Drop, recreate and reseed the database                            |
| `npm run typecheck`    | TypeScript, no emit                                               |

## A five-minute tour

1. Sign in as the demo learner. The seeded data already has two Spaces, two
   Projects and two processed PDFs.
2. Open **Spaced Repetition & Retrieval → AI Tutor**. Ask
   *"What is the testing effect?"* — you get a streamed answer with a page
   citation you can expand to see the source passage.
3. Ask *"How do I bake sourdough bread?"* — the tutor declines, because your
   materials do not cover it.
4. Ask *"What is the greenhouse effect?"* — it also declines. That content
   exists, but in your *other* project. Projects do not leak.
5. Go to **Quiz** and take one. Watch the "Chosen because" line: it names the
   concept, the mastery level and why the difficulty moved.
6. Answer a written question. You get rubric-level feedback and a live mastery
   delta.
7. **Growth** shows per-concept change; **Analytics** shows activity,
   performance and AI cost.
8. Sign in as the admin to see platform activity, AI usage and cost, system
   health, and the AI evaluation suite — run it from the dashboard.
